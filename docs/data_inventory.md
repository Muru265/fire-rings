## Surprises / flags (reviewed 2026-11-09)

1. **NRT files have no `type` column.** The type 1/2/3 filter can only be applied to archive rows.
   NRT rows (Aug–Nov 2026 VIIRS, Sep–Nov 2026 MODIS) rely on the static-source mask alone.
   Unified schema stores `type = NULL` for NRT; the filter keeps NULL.
2. **Archive and NRT do not overlap in date.** VIIRS archive ends 2026-07-31 → NRT starts 2026-08-01;
   MODIS archive ends 2026-08-31 → NRT starts 2026-09-01. NRT-vs-archive dedupe is still implemented
   (prefer archive on matching stream+date) but is expected to drop 0 rows.
3. **S-NPP `instrument` = "SNPP"**, not "VIIRS". Stream must be derived from `satellite`
   (Terra/Aqua/SNPP/N20/N21), never from `instrument`. These are the only five satellite codes found.
4. **MODIS version switches 6.03 → 61.03 on 2023-01-01** inside the archive (both C6.1 processing labels).
   No change in columns or confidence scale; treated as one product.
5. **Mauritius file includes Rodrigues** (lon ≈ 63.4 E; 3 MODIS / 21 S-NPP / 23 NOAA-20 / 9 NOAA-21 archive rows)
   and **does not include Réunion** (no lon < 57.34). The region is "Republic of Mauritius" as delivered.
6. **Type 2 (other static land source) is large in India**: 924,256 of 8.73 M S-NPP archive rows (10.6%);
   95,601 of 1.92 M MODIS. Type 1 (volcano) is negligible (91 / 25). Dropped per filter rule 4.
7. **VIIRS low-confidence share** ≈ 17% in India, ≈ 10% elsewhere. Dropped for both sensors.
8. **Satellite outages vs "no fire".** S-NPP has a 16-day hole 2022-07-26 → 2022-08-11 in Madagascar
   (S-NPP safe-mode event) — inside Madagascar's burning season. Short winter gaps in Terra/Aqua are
   mostly "no fire", not outages. ⇒ Coverage (O/D) needs a per-stream **operating-days** proxy that is
   not region-specific: planned = days with ≥1 detection in the largest file (Australia) for that stream.
9. **Clip-box sizes** (archive rows inside box): Punjab MODIS 474,898 · S-NPP 1,378,386 · NOAA-20 721,514 ·
   NOAA-21 186,305. SE Australia MODIS 622,477 · S-NPP 1,800,448 · NOAA-20 1,215,648 · NOAA-21 307,105.
10. MODIS NRT for Mauritius has only 12 rows (all Aqua) — expected for a low-fire island.
11. All `acq_time` values are 4-digit HHMM; no non-numeric FRP; lat/lon within each country's extent.
